# Word & Line Counter CLI

A simple Node.js command-line application that reads a text file and counts the number of lines, words, and characters.

## Features

- Count lines
- Count words
- Count characters
- Read files using fs/promises
- Handle missing files using try/catch
- Accept filenames using process.argv

## Requirements

- Node.js
- npm

## Usage

Run the program:

```bash
npm start sample.txt
